# 🍔 Food Order System (Spring Core)

---
## 📌 Overview

---
## ✨ Features
- Add Food
- View Menu
- Place Order
- View Orders

---
## 🧠 Concepts Used
- Dependency Injection
- Multi-service architecture
- Bean Configuration
- Layered Design

## 🛠️ Tech Stack
- Java
- Spring Core
- Maven
